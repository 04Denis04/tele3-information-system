# Информационная система оператора сотовой связи «ТЕЛЕ 3»

Учебный веб-проект для автоматизации работы оператора сотовой связи. Приложение разработано на **Python + Flask**, а для хранения данных используется **PostgreSQL**.

## Возможности

- авторизация пользователей;
- ролевая модель доступа;
- управление абонентами и SIM-картами;
- работа с тарифами и услугами;
- учёт платежей, звонков и SMS;
- личный кабинет абонента;
- обращения в техническую поддержку;
- журналирование событий безопасности.

## Технологии

- Python 3;
- Flask;
- PostgreSQL;
- psycopg2;
- HTML, Bootstrap;
- unittest;
- GitHub Actions.

## Структура проекта

```text
app/                    Flask-приложение
  routes/               маршруты и бизнес-логика
  templates/            HTML-шаблоны
.github/workflows/       автоматический запуск smoke-теста
tests/test_smoke.py      простой smoke-тест страницы входа
config.py                конфигурация приложения
run.py                   точка запуска
requirements.txt         зависимости
migrate_tickets.sql      дополнительная миграция БД
```

## Локальный запуск

### 1. Создание виртуального окружения

Windows PowerShell:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

Linux:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 2. Установка зависимостей

```bash
python -m pip install -r requirements.txt
```

### 3. Настройка переменных окружения

Пример переменных находится в `.env.example`. Реальные пароли и ключи нельзя публиковать в репозитории.

Минимальный пример для PowerShell:

```powershell
$env:SECRET_KEY="your-random-secret"
$env:DB_HOST="localhost"
$env:DB_PORT="5432"
$env:DB_NAME="tele3"
$env:DB_USER="tele3_app"
$env:DB_PASSWORD="your-password"
```

### 4. Запуск приложения

```bash
python run.py
```

После запуска приложение будет доступно по адресу `http://127.0.0.1:5000`.

## Автотест

В проект добавлен простой smoke-тест. Он проверяет, что Flask-приложение создаётся, страница `/login` открывается с кодом `200`, а форма входа отображается.

Запуск:

```bash
python -m unittest discover -s tests -v
```

Ожидаемый результат:

```text
test_login_page_is_available ... ok
```

При каждом `push` и `pull request` этот тест автоматически запускается через GitHub Actions.

## Важное замечание о базе данных

Скрипт `setup.sh` ссылается на файл `tele3_database.sql`, однако в исходном архиве этого файла не было. Для полного развёртывания базы данных необходимо добавить в репозиторий исходный SQL-файл со схемой и начальными данными либо актуализировать инструкцию установки.
